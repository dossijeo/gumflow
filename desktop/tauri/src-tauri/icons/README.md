# GUMFLOW application icon

These PNG/ICO files were rendered from the existing GUMFLOW 6.1 `gum()` drawing
function on a square dark background, then resized without changing the character
design. No third-party logo, font file or newly generated illustration is included.

`icon.png` is the 512-pixel source capture; the other images are packaging sizes.
The icon is covered by the same provenance/terms as the original game artwork.
